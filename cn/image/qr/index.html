使用说明

QR Code 产生器可以把网址、文本、Wi-Fi 设置或联系信息转成 QR Code，支持中文内容，可调整容错等级、大小与颜色，输出 PNG 直接用于传单、名片、菜单或演示文稿。容错等级越高，QR Code 被弄脏或中间放 Logo 时越能被读取，但图案也越密；印刷尺寸建议至少 2×2 公分，前景要比背景深、对比要够，避免使用浅色前景。「读取」功能则可以上传截屏或照片，解码其中的 QR Code 内容，适合在电脑上处理别人传来的 QR Code 截屏。产生使用 qrcode-generator（MIT），读取使用 jsQR（Apache-2.0），都在浏览器内运行。小提醒：扫描来路不明的 QR Code 前请确认网址，近年常见假冒停车费、包裹通知的 QR Code 诈骗。所有处理都在你的浏览器内完成，图片不会上传到任何服务器。

常见问题

QR Code 会过期吗？

本工具产生的是静态 QR Code，内容直接写在图中，不会过期。

可以放 Logo 吗？

选容错 H，再用其他软件在中间放小 Logo（不超过面积 20%）。

扫不到怎么办？

提高对比、加大尺寸，或缩短网址。

读取时找不到？

请裁切让 QR Code 占画面大部分，并确保清晰。
