使用说明

Base64 是把二进位文件转成纯文本的编码方式。把小图标转成 Base64 Data URL（data:image/png;base64,…）后，可以直接写进 HTML 的 img src、CSS 的 background-image、Email 范本或 JSON API，少一次网络请求，也不用另外管理图档。缺点是 Base64 会比原档大约 33%，而且不能被浏览器单独缓存，所以只建议用在几 KB 以内的小图标；照片等大图仍应使用一般图档。本工具会显示转换前后的大小，并提供一键拷贝。反向功能则可以把 API 回传、程序记录中的 Base64 字符串粘贴，还原成图片预览与下载；没有 data: 开头时会当作 PNG 处理。所有处理都在你的浏览器内完成，图片不会上传到任何服务器。

常见问题

Base64 会变大多少？

约增加 33%。

什么时候适合用？

几 KB 以内的小图标、Email 范本或需要单一文件时。

解码失败怎么办？

确认字符串完整，没有多余空白或被截断。

数据安全吗？

转换在浏览器内完成，不会上传。
