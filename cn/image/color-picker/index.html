使用说明

看到一张喜欢的照片或品牌视觉，想知道它用了哪些颜色？这个取色工具会先用「中位切分」算法分析整张图片，找出最具代表性的主色，依占比由多到少排列成调色板，并列出每个颜色的 HEX、RGB 与 HSL 数值，可以直接贴到 Canva、Figma、PowerPoint 或 CSS 中使用。接着你也可以在图片上任意点一下，即时取得该像素的颜色。做演示文稿、网站或社群图卡时，从主视觉照片取色来搭配文本与按钮，画面会更协调；一般建议选一个主色、一个辅助色、一个强调色。注意屏幕显示会受色彩描述档影响，印刷用途请另外换算 CMYK 并打样确认。所有处理都在你的浏览器内完成，图片不会上传到任何服务器。处理完成后可以直接预览并下载，手机可以长按图片保存到相册；大图在较旧的手机上可能需要几秒钟，请耐心等待。

常见问题

HEX 和 RGB 差在哪？

同一个颜色的不同写法，HEX 常用于网页，RGB 用于设计软件。

可以取得 CMYK 吗？

目前提供 HEX、RGB、HSL；印刷请在设计软件换算并打样。

调色板怎么算的？

以中位切分法把像素分群，取每群平均色。

透明区域会算进去吗？

透明度低于 50% 的像素会被忽略。
