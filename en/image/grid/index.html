How to use

Create seamless Instagram grids or split a long image into parts. Tiles are numbered from top-left to bottom-right; for an Instagram grid, post from the last tile backwards. Everything runs in your browser — your images are never uploaded.

FAQ

In what order should I post?

Post the bottom-right tile first and finish with the top-left.

Can I choose other grids?

Yes, set any number of rows and columns.
