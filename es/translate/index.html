Cómo se usa

Pega hasta 1000 caracteres, elige el idioma de destino y obtén una traducción fluida. Útil para fichas de producto, correos, menús y carteles de viaje. Para que siga siendo gratis hay un límite diario compartido, visible en “restantes hoy”. El texto se envía a Cloudflare Workers AI para traducirlo y no se guarda; no introduzcas contraseñas ni datos sensibles.

Preguntas frecuentes

¿Se guarda mi texto?

No, Cloudflare Workers AI lo traduce al momento y este sitio no lo guarda.

¿Cuánto puedo traducir de una vez?

Hasta 1000 caracteres por solicitud.

¿Por qué está desactivado el botón?

Puede que se haya agotado la cuota compartida de hoy; se reinicia a medianoche (hora de Taipéi).
