Cómo se usa

Útil para incrustar iconos pequeños en CSS o correos, o recuperar una imagen de un data URI. Todo se procesa en tu navegador: tus imágenes nunca se suben.

Preguntas frecuentes

¿Cuándo usar Base64?

Solo con imágenes pequeñas; ocupa un 33 % más que el archivo.

¿Puedo decodificar un data URI?

Sí, pégalo y elige decodificar.
