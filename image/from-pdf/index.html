使用說明

想把 PDF 的某一頁貼到簡報、傳到 LINE 或 IG，或是網站只接受圖片上傳時，就需要把 PDF 轉成圖片。這個工具使用 Mozilla 開發的開源 PDF 引擎 pdf.js（Apache-2.0 授權），在你的瀏覽器裡逐頁繪製 PDF，輸出 JPG 或 PNG，多頁時可打包 ZIP 下載。解析度 72 DPI 適合螢幕快速瀏覽，150 DPI 是一般用途的平衡選擇，300 DPI 適合列印或需要看清小字，但檔案較大、處理較慢。為避免手機記憶體不足，一次最多轉換前 50 頁。合約、帳單、成績單等文件內容不會上傳到伺服器。加密或有密碼保護的 PDF 目前無法開啟；含特殊字型的 PDF 在少數情況下可能顯示略有差異。所有處理都在你的瀏覽器內完成，圖片不會上傳到任何伺服器。

常見問題

DPI 選多少？

分享選 150，列印或看小字選 300。

有密碼的 PDF 可以轉嗎？

目前不支援加密 PDF。

頁數有限制嗎？

一次最多 50 頁。

PNG 和 JPG 選哪個？

文字、表格選 PNG 較銳利；照片多選 JPG 檔案較小。
