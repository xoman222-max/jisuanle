使用說明

QR Code 產生器可以把網址、文字、Wi-Fi 設定或聯絡資訊轉成 QR Code，支援中文內容，可調整容錯等級、大小與顏色，輸出 PNG 直接用於傳單、名片、菜單或簡報。容錯等級越高，QR Code 被弄髒或中間放 Logo 時越能被讀取，但圖案也越密；印刷尺寸建議至少 2×2 公分，前景要比背景深、對比要夠，避免使用淺色前景。「讀取」功能則可以上傳截圖或照片，解碼其中的 QR Code 內容，適合在電腦上處理別人傳來的 QR Code 截圖。產生使用 qrcode-generator（MIT），讀取使用 jsQR（Apache-2.0），都在瀏覽器內執行。小提醒：掃描來路不明的 QR Code 前請確認網址，近年常見假冒停車費、包裹通知的 QR Code 詐騙。所有處理都在你的瀏覽器內完成，圖片不會上傳到任何伺服器。

常見問題

QR Code 會過期嗎？

本工具產生的是靜態 QR Code，內容直接寫在圖中，不會過期。

可以放 Logo 嗎？

選容錯 H，再用其他軟體在中間放小 Logo（不超過面積 20%）。

掃不到怎麼辦？

提高對比、加大尺寸，或縮短網址。

讀取時找不到？

請裁切讓 QR Code 佔畫面大部分，並確保清晰。
