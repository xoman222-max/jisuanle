使用說明

分享聊天截圖、訂單畫面、包裹單據或街景照片前，記得把電話、地址、姓名、帳號、條碼、車牌與路人的臉遮起來。這個工具可以用百分比滑桿選擇要遮蔽的矩形區域（全部設為 0、0、100、100 就是整張），並選擇馬賽克或模糊效果，強度越大越難辨識。請特別注意：輕微的模糊或太小的馬賽克格子，有可能被影像處理技術部分還原，遮蔽密碼、身分證號碼、信用卡號等敏感資料時，建議使用較大的格子，或乾脆用純色方塊蓋掉；條碼與 QR Code 只要遮住一部分仍可能被讀取，最好完整蓋住。需要遮多個區域時，可以把處理好的圖片重新選取，再遮下一個區域。所有處理都在你的瀏覽器內完成，圖片不會上傳到任何伺服器。處理完成後可以直接預覽並下載，手機可以長按圖片儲存到相簿；大張圖片在較舊的手機上可能需要幾秒鐘，請耐心等候。

常見問題

馬賽克能被還原嗎？

格子太小或模糊太輕有被部分還原的風險，敏感資訊請用大格子。

怎麼遮多個地方？

處理完後重新選取輸出的圖片，再遮下一處。

怎麼遮整張圖？

把左、上設為 0，寬、高設為 100。

QR Code 要遮多少？

建議完整遮住，部分遮蔽仍可能被掃描。
