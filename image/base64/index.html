使用說明

Base64 是把二進位檔案轉成純文字的編碼方式。把小圖示轉成 Base64 Data URL（data:image/png;base64,…）後，可以直接寫進 HTML 的 img src、CSS 的 background-image、Email 範本或 JSON API，少一次網路請求，也不用另外管理圖檔。缺點是 Base64 會比原檔大約 33%，而且不能被瀏覽器單獨快取，所以只建議用在幾 KB 以內的小圖示；照片等大圖仍應使用一般圖檔。本工具會顯示轉換前後的大小，並提供一鍵複製。反向功能則可以把 API 回傳、程式記錄中的 Base64 字串貼上，還原成圖片預覽與下載；沒有 data: 開頭時會當作 PNG 處理。所有處理都在你的瀏覽器內完成，圖片不會上傳到任何伺服器。

常見問題

Base64 會變大多少？

約增加 33%。

什麼時候適合用？

幾 KB 以內的小圖示、Email 範本或需要單一檔案時。

解碼失敗怎麼辦？

確認字串完整，沒有多餘空白或被截斷。

資料安全嗎？

轉換在瀏覽器內完成，不會上傳。
