護照用中翻英（姓名＋地址英譯）

辦護照、填國外網站或簽證表格時，把中文姓名轉成護照格式英文（如 CHEN, DA-WEN），把中文地址轉成中華郵政英文地址格式。全部在瀏覽器內轉換，不上傳。

怎麼用

姓名：輸入完整中文姓名，選擇拼音方式（沒特別需求選漢語拼音）。結果格式和護照一樣：姓氏全大寫、逗號、名字每個字用「-」隔開。如果名字裡有多音字（例如「樂」可唸 LE 或 YUE），下方會出現選單讓你選正確唸法。點「四種拼音比較」可看同一個名字在漢語、通用、威妥瑪、國音第二式的寫法。

地址：貼上完整中文地址，會依中華郵政格式由小到大排列：樓層 → 號 → 弄 → 巷 → 段 → 路名 → 區 → 縣市 → Taiwan (R.O.C.)。路名優先採用中華郵政官方譯名；找不到時會用拼音規則翻譯並提醒你核對。

使用範例

陳大文 → CHEN, DA-WEN

CHEN 是姓（Surname），護照「姓」欄填 CHEN；DA-WEN 是名（Given name），填在「名」欄。國外訂機票時 Last name 填 CHEN、First name 填 DAWEN 或 DA-WEN（照護照）。

歐陽娜娜 → OUYANG, NA-NA

複姓「歐陽」連寫成 OUYANG，不加短橫。

曾志偉 → ZENG, ZHI-WEI

「曾」當姓氏唸 ㄗㄥ（ZENG），不是「曾經」的 CENG；單（SHAN）、仇（QIU）、區（OU）、解（XIE）、樂（YUE）等姓氏也會自動用正確讀音。

呂秀蓮 → LU, XIU-LIAN

依領事事務局對照表，漢語拼音的ㄌㄩ寫作 LU；選通用拼音會得到 LYU, SIOU-LIAN。

臺北市大安區忠孝東路四段100巷5弄3號2樓之1

→ 2F.-1, No. 3, Aly. 5, Ln. 100, Sec. 4, Zhongxiao E. Rd., Da'an Dist., Taipei City, Taiwan (R.O.C.)。2F.-1 是「2樓之1」，No. 3 是 3 號，Aly. 是弄（Alley），Ln. 是巷（Lane），Sec. 是段，E. 是「東」，Dist. 是區。國外網站常分成多欄：Address line 1 填「2F.-1, No. 3, Aly. 5, Ln. 100」，Address line 2 填「Sec. 4, Zhongxiao E. Rd., Da'an Dist.」，City 填 Taipei City，Postal code 填郵遞區號，Country 選 Taiwan。

新北市板橋區中山路一段161號

→ No. 161, Sec. 1, Zhongshan Rd., Banqiao Dist., New Taipei City, Taiwan (R.O.C.)。

常見問題

呂、女這類「ㄩ」的字怎麼拼？

依外交部領事事務局「護照外文姓名拼音對照表」，漢語拼音的ㄌㄩ、ㄋㄩ寫成 LU、NU（護照不能用 ü）；通用拼音則是 LYU、NYU。若擔心和「盧 LU」混淆，可改選通用拼音，但同一家人姓氏拼法應一致。

我已經有護照了，可以換成這裡的拼法嗎？

原則上不行。換發護照應沿用舊護照的外文姓名；只有拼音與國家語言讀音不符（限一次）、與直系血親或兄弟姊妹姓氏拼法不同等情形可申請變更。請以舊護照為準。

名字中間一定要加「-」嗎？

不一定。領事事務局說明，名字音節中間的短橫是為了方便斷音，不加也可以，申請時說明即可。

複姓怎麼處理？

歐陽、司馬、諸葛、上官、張簡、范姜等複姓會自動辨識並連寫（例如 OUYANG）。若自動判斷錯誤，可在「姓氏字數」手動指定 1 或 2 個字。

地址英文一定要這樣寫嗎？

國內郵件寫中文最準確。英文地址用於國外網購、簽證、銀行或證件表格，格式依中華郵政「中文地址英譯」：由小到大，最後是 Taiwan (R.O.C.)。路名優先使用中華郵政資料中的官方譯名。

資料會上傳嗎？

不會。姓名與地址都在你的瀏覽器內轉換，不會送到伺服器。
