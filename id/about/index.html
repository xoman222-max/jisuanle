Tentang

jisuanle menyediakan alat gambar gratis — hapus background, kompres, konversi, pas foto, PDF, dan lainnya — serta penerjemah, konversi mata uang, dan kalkulator harian. Alat gambar berjalan sepenuhnya di browser, sehingga file tidak pernah meninggalkan perangkat Anda.

Situs ini berawal di Taiwan (nama 算了 berarti “ayo hitung” sekaligus “ya sudahlah”).

Proyek open-source yang kami gunakan tercantum di halaman lisensi open-source.
