AI 번역기

0 / 1000

🔒 ‘번역’을 누르면 텍스트가 번역을 위해 Cloudflare Workers AI로 전송되며 저장되지 않습니다. 비밀번호나 주민등록번호 같은 민감한 정보는 입력하지 마세요.

문제 신고 / 제안계산 오류, 고장, 원하는 기능이 있나요? 알려 주세요

사용 방법

최대 1000자를 붙여 넣고 번역할 언어를 고르세요. 상품 페이지, 이메일, 여행지 메뉴판과 표지판 번역에 유용합니다. 무료 제공을 위해 사이트 전체 하루 한도가 있으며 ‘오늘 남은 횟수’로 확인할 수 있습니다. 텍스트는 번역을 위해 Cloudflare Workers AI로 전송되지만 저장되지 않습니다. 비밀번호나 개인정보는 입력하지 마세요.

자주 묻는 질문

입력한 글이 저장되나요?

아니요. Cloudflare Workers AI가 실시간으로 번역하며 이 사이트는 저장하지 않습니다.

한 번에 몇 자까지 되나요?

요청당 1000자까지입니다.

버튼이 눌리지 않는 이유는?

오늘의 공용 한도가 소진되었을 수 있습니다. 매일 자정(대만 시간)에 초기화됩니다.
