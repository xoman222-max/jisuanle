사용 방법

과제, 영수증, 경비 정산에 유용합니다. 순서와 페이지 크기만 고르면 PDF가 완성됩니다. 가로 이미지는 가로 페이지로 자동 설정할 수 있습니다. 모든 처리는 브라우저 안에서 이루어지며 이미지는 업로드되지 않습니다.
