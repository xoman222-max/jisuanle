PDF를 이미지로

처리 결과

🔒 이미지는 브라우저에서만 처리되며 업로드되지 않습니다.

문제 신고 / 제안계산 오류, 고장, 원하는 기능이 있나요? 알려 주세요

사용 방법

메신저 공유나 발표 자료에 넣기 좋습니다. 화면용은 150DPI, 인쇄용은 300DPI를 추천합니다. 모든 처리는 브라우저 안에서 이루어지며 이미지는 업로드되지 않습니다.

자주 묻는 질문

PDF가 업로드되나요?

아니요, PDF.js가 기기에서 렌더링합니다.

몇 페이지까지 되나요?

파일당 처음 50페이지까지입니다.
